또 찾은 이슈들.

1. 자동완성 ui 팝업이 분할시에 뜨는 위치가 불안정하다.
2. 자동완성 ui 가 생긴 채로 커서를 옮기면 자동완성 ui 가 esc 를 누르기 전까지 커서를 졸졸 따라다닌다.
3. 분할하고 뭐 레이아웃 그룹 만들고 탭 많이 생성하고 그러다보면 랙이 엄청나게 심해진다.
4. 에디터 분할 후 에디터들 사이 간격을 조절할 때 렉이 심하다.
5. Set Project Master Directory 기능에 있는 index 기능은 프로젝트를 열 때마다 다시 Re-index 를 해줘야 해서 불편하다.
6. 가로로 길게 쓰다가 현 보이는 에디터 범위에서 탈출했을 때 가로 스크롤이 팔로우하지 않는다.(동일하게 세로 스크롤도 팔로우하지 않는다.)
7. 영어 이외 문자들을 쓸 때, 에디터 분할 시에, 맨 왼쪽 첫번째 창에 지금 현재 조합중인 문자가 뜨고 사라지고 뜨고 사라지고 반복한다.
8. Set Project Master Directory 기능이 진짜 유의미하려면 렉이 보이는 이상으로 줄어야 할텐데 딱히 체감이 없다.
9. 여전히 한국어 선택후 복사 붙여넣기 안됨. (suisei 내부에선 가능하나 suisei 에서 복사한걸 외부로 붙여넣기가 불가능)
10. () 안에 한국어를 입력할 때, (끝까지 입력 후) 닫음괄호 바로 뒤에 커서를 둔 상태일 때, 커서를 다른곳에 클릭하면 닫음괄호 바로 뒤에 있던 한국어 문자가 그 커서를 따라 이동하는 이상한 버그가 있다.
