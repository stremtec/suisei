# Suisei 라이선스 정책

> 개정 2026-08-05 (v1.1 — 법률 리뷰 반영). 법적으로 우선하는 본문은
> [`LICENSE`](../LICENSE) (Suisei Source License v1.1 · SPDX
> `LicenseRef-Suisei`)이다. 이 문서는 정책 설명이며, 이 문서와 LICENSE가
> 다르면 LICENSE가 우선한다.

## 1. 한 줄 요약

**Suisei는 source-available 이다** — 오픈소스가 아니고, 클로즈드 소스도 아니다.
소스는 공개되지만 조건이 붙는다: 개인·비상업 이용은 무료, 상업 이용은 별도 계약.
"오픈소스"라고 부르지 않는 이유는 OSI 정의(OSD 6조, 이용 분야 차별 금지)와
양립하지 않기 때문이고, 그건 `LICENSE` §10 이 이미 명시하고 있다.
개발 중인 소스, 출시 예정/출시된 버전의 소스, 그리고 그 바이너리(`.app`)는
공개하지 않는다. GitHub에는 **현재 버전보다 1년
뒤처진 직전 개발본**(예: `2026dev`)만 "공개 릴리즈"로 게시하고, **그 버전에
한해서** 개인·비상업적 포크·수정을 허용한다.

## 2. 3-층(3-tier) 라이선스 구조

| 문서 | 적용 대상 | 용도 |
|---|---|---|
| **`LICENSE`** — Suisei Source License (`LicenseRef-Suisei`) | 지연 공개된 dev 소스 스냅샷 (`2026dev` 등 Released Version) | 소스 이용·포크·수정 규율 |
| **`EULA`** — Suisei End User License Agreement | 배포되는 실행 바이너리 (`2027 .app` 등 Unreleased Version) | 실행·역공학·재배포·상업 이용 규율 |
| **`CLAs/SUISEI-CLA.md`** — Suisei Contributor License Agreement | 외부 기여 | 기여가 비공개 제품에 포함·재라이선스되는 권리 확보 |

> 구조상의 핵심: **Unreleased(미공개/출시) 버전을 Source License로 규제하지
> 않는다.** 출시 바이너리는 별도 EULA가, 비공개 소스는 저작권·영업비밀·NDA·
> 접근통제가 보호한다. Source License는 "공개된 것만 다룬다".

## 4. 공개 일정 — "1년 지연 공개"

메이저 버전을 **연도 이름**으로 출시한다. `N` 버전이 출시되는 시점에 직전
개발 최종본을 `(N-1)dev` 태그로 공개한다.

| 출시 시점 | 그때 공개되는 릴리즈 | 비고 |
|---|---|---|
| 2027 출시 | 2026dev | 현재 개발 트리는 `2027` 개발본 = **Unreleased** |
| 2028 출시 | 2027dev | 버전별로 공개 당시의 라이선스가 적용 |
| 2029 출시 | 2028dev | |

## 5. 사용 허용 범위

### 5.1 개인·비상업적 사용 (무료)

> 무료 EULA는 **개인(자연인)만** 대상이다 (EULA §2 "You"). 학교·정부·
> 비영리 단체의 단체 사용과 법인의 사용은 모두 별도 계약 대상이며,
> 교육·비영리 단체용 무료 라이선스 도입은 추후 검토 사항이다.

- 사적 복제(포크) — 로컬, 본인만 접근 가능한 저장소
- 사적 수정, 개인 빌드·실행
- 학습·연구·평가

### 5.2 상업적 이용·단체 이용 — 별도 서면 계약 필요

본 EULA는 개인만 대상이므로, 아래 어느 하나라도 해당하면 목적이
비영리여도 별도 계약이 필요하다 (EULA §4, §2 Organizational Use):

- 상업 목적·수익 창출·상업적 이점을 위한 사용 (Commercial Use)
- **영리 기업의 내부 운영**(사내 도구, 내부 개발 환경, 직원 업무 등)
- **학교·정부기관·비영리단체의 단체 설치/사용** (Organizational Use)
- 법인·개인 지위와 무관, 무료 사용 여부와 무관

### 5.3 금지 (모든 경우)

- 파생물·릴리즈의 공개 배포 (공개 저장소 게시·판매·대여·임베드)
- 공개되지 않은 버전의 소스 접근·복제·스크래핑
- 공개되지 않은 릴리즈(바이너리) 역공학 — **단, 법령이 강행적으로 허용하는
  범위(예: 한국 저작권법 제101조의4 호환 정보 획득)는 예외**
- 미공개 코드를 파생물에 통합

## 6. 파생물(Derivative Work)이 아닌 것

Suisei가 IDE 제품이므로 **IDE 산출물·생태계는 라이선스 밖**임을 명문화했다
(LICENSE §6):

| 구분 | 정의 | 규율 |
|---|---|---|
| **User Works** | Suisei로 작성·편집·컴파일한 코드·문서·바이너리 | Suisei 파생물이 아님 — 자유롭게 사용·배포 |
| **Independent Works** | 공개 API·IPC·플러그인 인터페이스로만 통신하는 플러그인·확장·툴 | Suisei 파생물 아님 — 자신의 조건으로 배포 가능 (Suisei 코드 미포함 시) |
| **Third-Party Components** | 저장소에 포함된 외부 오픈소스 요소 | 각각의 라이선스 적용 |

## 7. 포크 규칙

**할 수 있는 것:** 사적 복제·수정·빌드 (개인 비상업적).

**할 수 없는 것:** 공개 배포, 상업적 이용(서면 허락 전).

**명시 의무:** 파생물 어디든 아래 표시를 유지한다 (소스 트리 + 앱이라면
About 화면):

```
This software is derived from Suisei
(https://github.com/stremtec/suisei).
```

**라이선스 무단수정 금지:** 파생물은 LICENSE를 **원문 그대로** 포함해야 하고,
조항 수정·삭제·축약·다른 라이선스로의 대체는 금지된다 (Suisei 부분에 한정).
요약·번역본 병기는 허용되되 "영문 원문 우선"을 명시해야 한다. 위반 시 라이선스
자동 종료 (§9). 원칙상 파생물 수령자가 발생할 수 있는 유일한 경로는 개발자의
서면 허가에 의한 배포다 — 그 경우 명시 의무가 수령자·후속 포크에 전파된다.

## 8. 외부 기여와 CLA

- 개발 트리는 비공개이므로, **외부 기여는 공개된 Released Version(예:
  `2026dev`)을 대상으로만** 받는다.
- 기여를 제출하는 순간 [Suisei CLA](../CLAs/SUISEI-CLA.md)에 동의한 것으로
  간주된다 (일반 OSS보다 이 모델에서 CLA 중요도가 훨씬 높다).
- CLA에 따라 기여물은 Stremtec의 **비공개 제품(2027 등)에 포함·독점적
  재라이선스가 가능**하다 (영구·전세계·취소 불가·무상·재허여 가능). 저작권
  자체는 기여자에게 남는다 (양도 아님).
- 기여자는 자신의 기여가 제3자 권리/법률을 위반하지 않음을 보증한다.

## 9. 문구 설계 메모 (왜 이렇게 썼는가)

- **`work built from it`를 쓰지 않는다**: Suisei로 만든 앱·바이너리가
  파생물처럼 오독되는 것을 막기 위해 "Released Version 또는 그 기반 파생물"로
  좁히고, §6(a) User Works safe harbor를 뒀다.
- **revocable 대신 irrevocable + §9 예외**: 공개 이후 정상 사용권을 사후
  철회하지 않는다는 신뢰성. 미래 버전 라이선스 변경 가능성은 §5가 별도로 둔다.
- **역공학 금지에 법령 예외**: "except to the extent such restriction is
  prohibited … by applicable law" — 금지 가능한 최대 범위까지 금지하면서
  강행규정(한국 저작권법 §101조4)과 정면 충돌하지 않게 한다.
- **Unreleased 의무를 Source License가 독점하지 않는다**: EULA로 분리하고,
  비공개 소스 보호는 라이선스+저작권+영업비밀+NDA+접근통제가 함께 담당한다.
- **warranty/책임**: "TO THE MAXIMUM EXTENT PERMITTED BY APPLICABLE LAW" —
  약관법상 무효가 되는 고의·중과실 책임 배제 범위를 회피.
- **copyleft 단정 완화**: "이 라이선스와 일반적으로 양립 불가능한 조건
  (GPL 포함)"으로 서술.
